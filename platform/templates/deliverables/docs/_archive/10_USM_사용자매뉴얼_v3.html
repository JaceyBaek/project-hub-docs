1.화면 카탈로그

각 화면의 주요 영역에 번호를 붙여 동작을 설명합니다. 화면 ID는 화면정의서(SCR)와 1:1 매핑됩니다.

[스크린샷 · SCR-001 기안문 작성]

기안문 작성 SCR-001

  1. ① 양식 선택 드롭다운 — 사내 표준 양식 선택
  2. ② 제목 입력 (80자 이내)
  3. ③ 본문 에디터 — 30초 자동 저장
  4. ④ 첨부 영역 — 드래그 업로드
  5. ⑤ [임시저장] / [상신]
[스크린샷 · SCR-002 결재선]

결재선 지정 SCR-002

  1. ① 조직도 탐색 · 사용자 검색
  2. ② 결재자/합의자/참조자 슬롯
  3. ③ 순서 드래그 재정렬
  4. ④ [저장] → [상신하기]
[스크린샷 · SCR-003 결재 처리]

결재 처리 SCR-003

  1. ① 문서 미리보기
  2. ② 이전 결재자 의견
  3. ③ 의견 입력란
  4. ④ [승인] [반려] [보류]
[스크린샷 · SCR-004 문서함]

문서함 SCR-004

  1. ① 탭 (받은/보낸/진행/완료)
  2. ② 검색 · 필터
  3. ③ 문서 목록 · 상태 배지
  4. ④ 일괄 작업 (Export 등)
