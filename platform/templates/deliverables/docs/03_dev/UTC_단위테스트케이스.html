1.개요

본 문서는 FUNC 산출물의 기능별 단위 테스트 케이스를 정의한다. Given/When/Then 포맷을 사용하고, 각 케이스는 상위 FUNC와 추적된다.

3.케이스 상세

UTC-001 · 임시저장 — 정상
  • Given 로그인된 사용자 U1, 양식 F-001 활성
  • When PUT /drafts/d-1 with {title:"휴가신청", bodyHtml:"…1KB"}
  • Then 200 + {id:"d-1", version 증가}, DB draft.updated_at 갱신
UTC-002 · 본문 50KB 초과
  • Given 본문 51KB
  • When PUT /drafts/d-1
  • Then 413 + BODY_TOO_LARGE
UTC-010 · 결재 승인 정상
  • Given 결재선상의 U2, 상태=PENDING
  • When POST /approvals/a-1/decisions {decision:"APPROVE"}
  • Then 200, 다음 결재자 큐 적재, 감사 로그 1건
UTC-011 · 반려 의견 누락
  • Given 결재자, 상태=PENDING
  • When POST decisions {decision:"REJECT", comment:""}
  • Then 422 + VALIDATION_FAILED
UTC-012 · 권한 없음
  • Given 결재선 외 사용자 U3
  • When POST decisions {decision:"APPROVE"}
  • Then 403 + FORBIDDEN
