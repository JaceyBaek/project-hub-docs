## §1 개요

### 목적
요구사항부터 최종 운영 산출물까지 전 단계에 걸쳐 각 항목의 연결 상태를 추적하여 누락·불일치를 감지한다.

### 범위
본 프로젝트의 모든 산출물: REQ → FLW / SCR / ROLE / FUNC / ARC / DAT / API / SEC → UTC / ITS → OPM / USM / CFG / RUN

### 추적 상태 정의

| 상태 | 설명 |
|------|------|
| 추적완료 | 해당 항목이 대상 산출물에 ID로 명시됨 |
| 부분추적 | 대상 산출물에 관련 내용은 있으나 ID 연결 미완 |
| 미추적 | 대상 산출물에 반영되지 않음 |
| 해당없음 | 해당 산출물이 프로젝트에 미적용 |
