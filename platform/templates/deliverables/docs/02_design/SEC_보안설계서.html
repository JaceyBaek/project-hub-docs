1.개요 / 보안 목표

CIA 3요소(기밀성·무결성·가용성) 기준 보안 목표와 적용 범위 명시.
기밀성 (Confidentiality)
결재 내용·개인정보는 권한자만 접근. 전송 TLS 1.2+, 저장 AES-256.
무결성 (Integrity)
결재 이력 변조 불가 (append-only 감사 로그). 입력값 검증으로 injection 방어.
가용성 (Availability)
DDoS 방어 (rate-limit). Multi-AZ 배포. 장애 시 RTO ≤ 4시간.

적용 범위: API Gateway ~ App Server ~ DB ~ 감사 로그 파이프라인. 외부 SSO(IdP) 보안은 Azure AD 정책에 위임.

2.위협 모델 (STRIDE)

STRIDE 분류별 위협 식별 + 대응 통제. 최소 3건.
IDSTRIDE위협대응 통제위험도
EM2026-SEC-T01Spoofing 유효하지 않은 JWT로 다른 사용자 위장 서명 검증 (RS256) + 만료 1h + Refresh Token Rotation High
EM2026-SEC-T02Tampering 결재 이력 DB 직접 수정으로 승인 조작 감사 로그 append-only (S3), DB 계정 최소 권한 (INSERT/SELECT만) Critical
EM2026-SEC-T03Elevation of Privilege 일반 사용자가 관리자 API 직접 호출 ROLE 기반 인가 (Scope 검증 + URL 패턴 whitelist) High
EM2026-SEC-T04Information Disclosure 오류 응답에 스택 트레이스·내부 경로 노출 공통 오류 핸들러 — 도메인 코드만 반환, 상세는 서버 로그에만 Medium
EM2026-SEC-T05Denial of Service API 대량 호출로 서비스 마비 Rate-limit: 사용자당 100 req/min / IP당 500 req/min (API Gateway) Medium

3.인증 / 인가

인증(AuthN) 방식과 인가(AuthZ) 모델 각각 명시. ROLE 정의는 ROLE 산출물 참조.
인증 (AuthN)OIDC (Azure AD) / Bearer JWT (RS256) / Access Token 1h, Refresh 8h
인가 (AuthZ)Scope 기반 + ROLE 매트릭스. 리소스 소유자 확인 (draft.submitter_id == caller). 관리자 전용 경로는 별도 Gateway 라우팅.
세션 관리Stateless (JWT). Refresh Token은 Redis에 저장, 로그아웃 시 즉시 무효화.
MFAAzure AD MFA 정책에 위임 (조직 정책 적용). 내부 별도 MFA 구현 없음.

4.암호화

전송 구간과 저장 데이터 암호화 각각 명시. 키 관리 방식 포함.
구분적용 대상방식 / 도구
전송 암호화클라이언트 ↔ API Gateway, 내부 서비스 간 mTLSTLS 1.2 이상 / Let's Encrypt + ACM
DB 저장 암호화RDS PostgreSQL 전체 볼륨AES-256 (RDS TDE)
파일 저장 암호화S3 첨부 파일, 감사 로그SSE-KMS (AWS KMS 관리 키)
PII 마스킹로그 내 사번·이름·이메일로그 필터 — data-pii 마킹 필드 자동 마스킹

5.입력 검증 / 취약점 대응

OWASP Top 10 기준 주요 항목 대응. 최소 3건.
ID위협 (OWASP)대응 방법
EM2026-SEC-C01A03 Injection (SQL) JPA/JPQL Parameterized Query 사용. 동적 SQL 금지. 리뷰 시 raw query 탐지 린트 적용.
EM2026-SEC-C02A07 XSS 응답 Content-Type: application/json 강제. HTML 렌더링 시 DOMPurify 적용. CSP 헤더 설정.
EM2026-SEC-C03A01 Broken Access Control 리소스 접근 시 소유자 확인 필수 (서비스 레이어 강제). 테스트 케이스: 타인 리소스 접근 시 403 확인.
EM2026-SEC-C04A05 Security Misconfiguration 환경변수 secrets는 AWS SSM만 사용. 운영 환경 디버그 모드 금지. 불필요한 포트/서비스 비활성화.

기록 대상 이벤트, 로그 형식, 보존 정책, 조회 방법 명시.
