§3 빠른 시작

  1. 브라우저에서 https://attendance.gsretail.internal 접속
  2. 사내 SSO 인증 페이지로 자동 이동 → 회사 계정으로 자동 로그인 (VPN 연결 상태에서)
  3. 메인 화면의 오늘 날짜·시각 확인 후 출근 버튼 클릭
  4. 위치 정보 허용 팝업 → 허용 선택 (위치 기반 재직 확인용)
  5. 화면 우측 상단에 "출근 기록 완료" 토스트 메시지 확인

§4 태스크별 사용 가이드

USM-T01 출퇴근 기록하기 전체 직원
  1. 1
    메인 화면 접속 → 상단 오늘 날짜와 현재 시각 확인
  2. 2
    메인 카드의 [출근] 버튼 클릭 (또는 QR 코드 스캔 — 사무실 입구 게시)
  3. 3
    위치 정보 허용 팝업이 나타나면 [허용] 선택. 거부 시 출근 기록이 처리되지만 위치 정보는 저장되지 않습니다.
  4. 4
    화면 우측 상단 "출근 기록 완료" 토스트 확인 → 출근 시각 표시
  5. 5
    퇴근 시: 메인 카드의 [퇴근] 버튼 클릭 → "퇴근 기록 완료" 토스트 확인 → 총 근무 시간 표시
⚠️
출근 버튼은 당일 1회만 활성화됩니다. 실수로 누른 경우 또는 기록 오류는 총무팀(슬랙 #근태문의)에 증빙 첨부 후 수정 요청하세요.
USM-T02 휴가 신청하기 전체 직원
  1. 1
    좌측 메뉴 → [결재 신청] 클릭
  2. 2
    결재 유형 선택: 연차 / 반차 (오전/오후) / 외출
  3. 3
    시작일시 ~ 종료일시 입력 (달력 선택기 사용)
  4. 4
    사유 입력 — 최소 10자 이상. 예: "가족 경조사 참석"
  5. 5
    [신청] 버튼 클릭 → 팀장에게 카카오워크/슬랙 알림 발송
  6. 6
    승인/반려 결과는 이메일 및 알림으로 통보됩니다. 결재 신청 메뉴에서 현재 상태 확인 가능
ℹ️
잔여 연차는 결재 신청 화면 상단에 표시됩니다. 반차는 0.5일, 연차는 1일 차감. 잔여 연차 부족 시 신청이 거부됩니다.
USM-T03 근태 통계 조회하기 전체 직원
  1. 1
    좌측 메뉴 → [근태 통계] 클릭
  2. 2
    조회 기간 선택: 일 / 주 / 월 탭 또는 직접 기간 입력
  3. 3
    카드 형태로 요약 표시:
    • 출근일수: 이번 달 출근한 날
    • 지각 횟수: 09:00 이후 출근 건수
    • 조퇴 횟수: 18:00 이전 퇴근 건수
    • 총 근무시간: 누적 근무 분을 시간으로 환산
    • 잔여 연차: 남은 연차 일수
  4. 4
    일별 상세 내역: 하단 표에서 날짜별 출근/퇴근 시각 및 상태 확인
USM-T04 팀원 결재 승인/반려하기 팀장 전용
  1. 1
    좌측 메뉴 → [결재함] 클릭 (팀장만 표시됨)
  2. 2
    대기 중인 신청 목록 확인 — 직원명, 유형, 기간, 사유 표시
  3. 3
    신청 건을 클릭하면 상세 정보 모달 표시
  4. 4
    의견(선택) 입력 후 [승인] 또는 [반려] 버튼 클릭. 반려 시 사유 입력 권장
  5. 5
    처리 즉시 신청자에게 이메일 및 알림 발송
⚠️
승인/반려 후 취소가 불가합니다. 잘못 처리한 경우 총무팀(슬랙 #근태문의)에 즉시 문의하세요.

§5 자주 묻는 질문 (FAQ)

FAQ-01. QR코드가 스캔되지 않을 때는 어떻게 하나요?
화면 밝기를 최대로 높이고, 카메라와 QR코드 사이 거리를 약 15~20cm로 유지한 후 다시 시도해 주세요. 그래도 안 되면 브라우저에서 직접 접속(https://attendance.gsretail.internal)하여 수동 기록 버튼을 사용하세요.
FAQ-02. 출퇴근 시간을 잘못 기록했을 때 수정할 수 있나요?
직원 본인은 수정할 수 없습니다. 총무팀 슬랙 채널 #근태문의에 ① 날짜, ② 정확한 시각, ③ 오류 증빙(출입 로그, 업무 메신저 기록 등)을 첨부하여 요청하세요. 처리는 영업일 기준 1~2일 소요됩니다.
FAQ-03. 결재 신청이 오랫동안 승인되지 않을 때는 어떻게 하나요?
우선 팀장에게 직접 확인 요청하세요. 신청 후 3 영업일 이상 처리가 없으면 HR 담당 최**에게 에스컬레이션하세요 (슬랙 DM 또는 이메일).
FAQ-04. 반차와 연차의 차이는 무엇인가요?
연차는 1일 전체 사용(연차 1일 차감), 반차는 오전 또는 오후 4시간 사용(연차 0.5일 차감)입니다. 외출은 연차 미차감이며 4시간 이내 자리를 비울 때 사용합니다.
FAQ-05. 휴일 근무는 어디에 기록하나요?
현재 버전(v0.2.1)에서는 휴일 근무 별도 기록 기능이 없습니다. 총무팀에 별도 양식으로 제출해 주세요. 다음 버전(v0.3.0)에서 지원 예정입니다.
