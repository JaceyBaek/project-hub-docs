§3 시크릿 관리 (keyring)

🔒
시크릿 값은 이 문서에 기재하지 않습니다. 아래 keyring 등록 명령을 실행하여 안전하게 등록하세요. .env에 평문으로 저장하면 보안 사고 즉시 발생 가능.
시크릿 IDkeyring 서비스keyring 키용도
P2605991-SEC-K01P2605991db_passwordPostgreSQL attendance_user 패스워드
P2605991-SEC-K02P2605991jwt_secretJWT HS256 서명 시크릿 (≥ 32자)
P2605991-SEC-K03P2605991payroll_api_key급여 시스템 연동 API Key

keyring 등록 명령

# PostgreSQL 패스워드 등록
python -c "import keyring; keyring.set_password('P2605991', 'db_password', 'YOUR_DB_PASSWORD')"

# JWT Secret 등록 (최소 32자 이상 랜덤 문자열 권장)
python -c "import keyring; keyring.set_password('P2605991', 'jwt_secret', 'YOUR_JWT_SECRET')"

# 급여 시스템 API Key 등록
python -c "import keyring; keyring.set_password('P2605991', 'payroll_api_key', 'YOUR_API_KEY')"

# 등록 확인
python -c "import keyring; print(keyring.get_password('P2605991', 'db_password') is not None)"
# → True 이면 정상 등록

애플리케이션에서 시크릿 로드

# app/core/secrets.py
from secrets_loader import inject_secrets

inject_secrets("P2605991", {
    "db_password": "DB_PASSWORD",
    "jwt_secret": "JWT_SECRET",
    "payroll_api_key": "PAYROLL_API_KEY"
})
# 이후 os.environ["DB_PASSWORD"] 로 접근 가능
