§1 공통 규격

Base URL

https://attendance.gsretail.internal/api/v1

인증

모든 엔드포인트는 아래 헤더를 필수로 포함해야 합니다.

Authorization: Bearer <JWT>
⚠️
JWT 미포함 또는 만료된 토큰으로 요청 시 HTTP 401 Unauthorized를 반환합니다. access token 유효 시간은 1시간이며, refresh token으로 갱신하세요.

공통 헤더

헤더값필수
Content-Typeapplication/jsonY (요청 바디 있을 때)
AuthorizationBearer <JWT>Y
Acceptapplication/json권장

공통 에러 응답 형식

{
  "error": {
    "code": "ERROR_CODE",
    "message": "사람이 읽을 수 있는 설명",
    "details": {}  // 선택적 추가 정보
  }
}

버전 관리

URL Path 버전 방식 (/api/v1/)을 사용합니다. 하위 호환 변경은 마이너 업데이트, 파괴적 변경은 /api/v2/로 분리합니다.

공통 에러 코드

HTTP 상태에러 코드설명
400BadRequest요청 형식 오류
401Unauthorized인증 토큰 없음 또는 만료
403Forbidden권한 없음
404NotFound리소스 없음
409Conflict상태 충돌
422ValidationError유효성 검사 실패
429TooManyRequestsRate Limit 초과
500InternalServerError서버 내부 오류

§2 엔드포인트 상세

POST /attendance/clock-in P2605991-API-001
직원의 출근 시각을 기록합니다. 당일 중복 출근은 허용되지 않습니다.

권한

ROLE-01 직원   ROLE-02 팀장   ROLE-04 시스템관리자

요청 Body

{
  "employee_id": "uuid",          // 직원 고유 식별자
  "timestamp": "2026-05-26T09:00:00+09:00",  // ISO8601 형식
  "location": {
    "lat": 37.5,                  // 위도
    "lng": 127.0                  // 경도
  }
}

응답

201 Created

{
  "data": {
    "record_id": "uuid",
    "employee_id": "uuid",
    "clock_in_at": "2026-05-26T09:00:00+09:00",
    "status": "normal"            // normal | late
  }
}

에러

HTTP에러 코드조건
409AlreadyClockedIn당일 이미 출근 기록이 존재함
404EmployeeNotFoundemployee_id에 해당하는 직원 없음
422ValidationErrortimestamp 형식 오류 또는 미래 시각
POST /attendance/clock-out P2605991-API-002
직원의 퇴근 시각을 기록하고 총 근무 시간(분)을 계산합니다.

권한

ROLE-01 직원   ROLE-02 팀장   ROLE-04 시스템관리자

요청 Body

{
  "employee_id": "uuid",
  "timestamp": "2026-05-26T18:00:00+09:00"
}

응답

200 OK

{
  "data": {
    "record_id": "uuid",
    "employee_id": "uuid",
    "clock_in_at": "2026-05-26T09:00:00+09:00",
    "clock_out_at": "2026-05-26T18:00:00+09:00",
    "work_minutes": 540,
    "status": "normal"
  }
}

에러

HTTP에러 코드조건
409NotClockedIn당일 출근 기록이 없음
422ClockOutBeforeClockIn퇴근 시각이 출근 시각보다 이전
409AlreadyClockedOut당일 이미 퇴근 기록이 존재함
GET /attendance/{employee_id}/stats P2605991-API-003
직원의 기간별 근태 통계를 조회합니다. 권한에 따라 조회 가능 범위가 제한됩니다.

권한

역할조회 가능 범위
ROLE-01 (직원)자신의 데이터만
ROLE-02 (팀장)소속 팀원 전체
ROLE-03 (HR담당자)전체 직원
ROLE-04 (시스템관리자)전체 직원

Query Parameters

파라미터타입필수예시설명
fromstringY2026-05-01조회 시작일 (YYYY-MM-DD)
tostringY2026-05-31조회 종료일 (YYYY-MM-DD)
group_bystringNmonth집계 단위: day | week | month

응답

200 OK

{
  "data": {
    "employee_id": "uuid",
    "period": {"from": "2026-05-01", "to": "2026-05-31"},
    "total_days": 22,
    "present_days": 20,
    "late_count": 1,
    "leave_days": 2,
    "total_work_minutes": 9600
  }
}

에러

HTTP에러 코드조건
403Forbidden타인의 데이터를 조회할 권한 없음
422InvalidDateRangefrom > to 또는 날짜 형식 오류
POST /leave/request P2605991-API-004
직원이 휴가(연차/반차/외출)를 신청합니다. 신청 후 팀장에게 승인 알림이 발송됩니다.

권한

ROLE-01 직원   ROLE-02 팀장

요청 Body

{
  "leave_type": "annual",          // annual | half | out
  "start_at": "2026-06-02T09:00:00+09:00",
  "end_at": "2026-06-02T18:00:00+09:00",
  "reason": "개인 사유로 인한 연차 사용"
}

응답

201 Created

{
  "data": {
    "request_id": "uuid",
    "leave_type": "annual",
    "start_at": "2026-06-02T09:00:00+09:00",
    "end_at": "2026-06-02T18:00:00+09:00",
    "status": "pending",
    "created_at": "2026-05-26T10:30:00+09:00"
  }
}

에러

HTTP에러 코드조건
422InvalidDateRange종료일이 시작일보다 이전
409OverlappingLeave동일 기간에 이미 결재 신청이 존재
422InsufficientLeaveBalance잔여 연차 부족
PUT /leave/request/{request_id}/approve P2605991-API-005
팀장이 휴가 신청을 승인 또는 반려합니다. 처리 후 신청자에게 이메일 알림이 발송됩니다.

권한

ROLE-02 팀장만 (자신의 팀원 신청 건에 한해)

요청 Body

{
  "approved": true,                 // true: 승인, false: 반려
  "comment": "승인합니다."           // string | null, 반려 시 사유 권장
}

응답

200 OK

{
  "data": {
    "request_id": "uuid",
    "status": "approved",           // approved | rejected
    "approved_by": "uuid",
    "comment": "승인합니다.",
    "processed_at": "2026-05-26T11:00:00+09:00"
  }
}

에러

HTTP에러 코드조건
403NotApprover해당 신청 건의 승인 권한 없음 (다른 팀 팀장 등)
404RequestNotFoundrequest_id에 해당하는 신청 없음
409AlreadyProcessed이미 승인/반려 처리된 신청

§3 Rate Limiting

ℹ️
Rate Limit 초과 시 HTTP 429 Too Many Requests를 반환하며, Retry-After 헤더에 재시도 가능 시각(초)을 포함합니다.
API 그룹대상 엔드포인트제한단위
출퇴근 기록POST /attendance/clock-in, POST /attendance/clock-out5회분당 (per user)
통계 조회GET /attendance/{id}/stats30회분당 (per user)
결재 처리POST /leave/request, PUT /leave/request/*/approve20회분당 (per user)
전체모든 엔드포인트200회분당 (per IP)
