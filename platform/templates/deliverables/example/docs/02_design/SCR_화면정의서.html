  • 네트워크 오류 시: "일시적 오류가 발생했습니다. 잠시 후 다시 시도하세요" (500 응답)

액션 흐름

  • 제출 버튼 클릭 → 프론트 유효성 검사 → POST /api/v1/leave-requests → 성공 시 "결재 신청이 완료되었습니다" 토스트 + 결재 목록 페이지 이동
  • 결재 신청 성공 → 팀장에게 이메일·슬랙 자동 알림 발송 (FLW-N06)

에러 처리

  • 잔여 연차 부족: "연차 잔여일수가 부족합니다. (잔여: N일)" 인라인 에러 (422)
  • 중복 결재 신청: "동일 기간에 이미 결재 신청이 있습니다" 토스트 (409)
  • 사유 미입력: "신청 사유를 10자 이상 입력하세요" 필드 인라인 에러
