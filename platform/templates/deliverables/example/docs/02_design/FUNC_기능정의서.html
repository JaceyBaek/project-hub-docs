§2 기능별 상세 명세

FUNC-001
clock_in — 출근 기록

함수 시그니처

async def clock_in(
    employee_id: str,
    timestamp: datetime,
    location: GeoPoint | None = None
) -> AttendanceRecord:

전제조건 (Pre-condition)

  • 당일(KST 기준 00:00~23:59) 이미 출근 기록이 없어야 함
  • 유효한 employee_id (활성 직원)
  • 호출자 인증 토큰의 employee_id와 파라미터 일치 (또는 admin)

처리 로직

  1. Redis에서 attendance:{employee_id}:{date}:clocked_in 키 존재 여부 확인 → 존재 시 AlreadyClockedInError(409)
  2. AttendanceRecord 생성: {employee_id, clock_in_at, location_in, status=normal}
  3. PostgreSQL에 INSERT (트랜잭션)
  4. Redis 캐시 무효화: stats:{employee_id}:* 패턴 삭제
  5. 감사 로그 이벤트 발행: attendance.clock_in

후조건 (Post-condition)

  • AttendanceRecord가 DB에 저장되고 id 반환
  • Redis 통계 캐시가 무효화됨

예외 처리

예외 클래스HTTP 코드발생 조건
AlreadyClockedInError409당일 출근 기록 이미 존재
EmployeeNotFoundError404employee_id가 DB에 없거나 비활성
AuthorizationError403다른 직원의 출근 기록 시도
FUNC-002
clock_out — 퇴근 기록

함수 시그니처

async def clock_out(
    employee_id: str,
    timestamp: datetime
) -> AttendanceRecord:

전제조건

  • 당일 출근 기록(clock_in_at)이 존재해야 함
  • 퇴근 시각이 출근 시각보다 이후여야 함

처리 로직

  1. 당일 출근 레코드 조회 → 없으면 NotClockedInError(409)
  2. clock_out_at = timestamp 업데이트
  3. work_minutes = (clock_out_at - clock_in_at).total_seconds() / 60 계산
  4. 09:00 이후 출근이면 status = late, 정시 퇴근 전이면 status = early_leave 판단 로직 적용
  5. Redis 통계 캐시 갱신 (해당 직원 키 무효화)
  6. 감사 로그 이벤트 발행: attendance.clock_out

예외 처리

예외 클래스HTTP 코드발생 조건
NotClockedInError409당일 출근 기록 없음
ClockOutBeforeClockInError422퇴근 시각이 출근 시각보다 이전
AlreadyClockedOutError409이미 퇴근 기록 존재
FUNC-003
get_attendance_stats — 근태 통계 조회

함수 시그니처

async def get_attendance_stats(
    employee_id: str,
    period: DateRange,
    requester_role: Role,
    requester_id: str
) -> AttendanceStats:

권한 체크

  • employee: requester_id == employee_id인 경우만 허용
  • manager: 소속 팀원 employee_id만 허용
  • hr / admin: 모든 employee_id 허용

캐싱 전략

  • Redis 키: stats:{employee_id}:{period_start}:{period_end}
  • TTL: 15분 (900초)
  • 캐시 미스 시 PostgreSQL 집계 쿼리 실행 후 캐시 저장

반환 구조

AttendanceStats {
    employee_id: str,
    period: DateRange,
    work_days: int,       # 출근 일수
    late_count: int,      # 지각 횟수
    early_leave_count: int, # 조퇴 횟수
    absent_count: int,    # 결근 횟수
    total_work_minutes: int, # 총 근무 분
    daily_records: list[DailySummary]
}
