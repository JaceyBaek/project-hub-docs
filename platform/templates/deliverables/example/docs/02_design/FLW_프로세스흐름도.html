§1 개요

근태관리 시스템의 핵심 비즈니스 프로세스 2종을 정의합니다. 각 흐름도는 액터(Actor), 시스템 처리 단계, 분기 조건, 예외 흐름을 포함합니다.

프로세스명관련 REQ노드 수주요 액터
출퇴근 기록 프로세스REQ-F01, REQ-B014개직원, FastAPI, Redis, PostgreSQL
결재 신청·승인 프로세스REQ-F03, REQ-B024개직원, 팀장, FastAPI, 알림 서비스

§4 예외 처리

예외 상황발생 노드처리 방법에러 코드
QR코드 인식 실패 FLW-N01 수동 입력 UI 폴백 제공. 3회 연속 실패 시 IT 지원 안내 팝업 표시. —
중복 출근 시도 FLW-N02 AlreadyClockedInError(409) 반환. 기존 출근 기록 표시 및 수정 안내. 409
퇴근 시 출근 기록 없음 FLW-N03 NotClockedInError(409) 반환. 관리자에게 수동 기록 요청 안내. 409
결재 시간 초과 (48시간) FLW-N07 상위 팀장 및 HR에 에스컬레이션 알림 자동 발송. —
급여 API 전송 실패 FLW-N09 최대 3회 재시도(지수 백오프). 재시도 후 실패 시 HR 담당자 이메일 알림. 502
Redis 캐시 장애 FLW-N04 캐시 없이 DB 직접 조회로 폴백. 캐시 복구 후 자동 재인덱싱. —
