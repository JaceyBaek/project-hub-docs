4. Trace 체계
요구사항 → 테스트까지의 추적 체인
REQ-F01 → FLW-001 → SCR-001 → FUNC-001 → UTC-001 → ITS-001
모든 ID는 프로젝트 prefix를 가진다 — 예: EACCT2026-REQ-F01. 각 항목은 data-trace-up / data-trace-down 양방향 속성으로 연결되며, 변환 시 dist/traceability.json으로 자동 추출된다.
5. RAG 변환 파이프라인
변환기 위치: tools/build-rag.mjs (프로젝트 루트의 공용 위치)
1. 입력
templates/deliverables/docs/**/*.html
(단계 폴더 재귀, 또는 각 프로젝트 docs/**/*.html)
2. 처리
AI-SKIP 제거 → 헤딩 prefix → 청크 분할 → frontmatter 생성
3. 출력
dist/*.md
dist/chunks.jsonl
dist/traceability.json
실행: npm i jsdom && node tools/build-rag.mjs
