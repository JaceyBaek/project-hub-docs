1.개요 · ID 체계

요구사항부터 단위/통합 테스트까지의 연결을 단일 뷰로 확인한다. 각 셀에는 하위 문서의 ID가 들어가며, Confluence에서는 Smart Link로 실제 페이지로 이동한다.

프로세스FLW-###프로세스흐름도

기능FUNC-###기능정의서
단위 테스트UTC-###단위테스트케이스
통합 테스트ITS-###통합테스트시나리오
권한ROLE-##권한정의서 (Cross-cut)
