1.개요

본 문서는 전자결재 시스템의 역할(Role)과 권한(Permission)을 정의한다. ABAC 보조 규칙은 §4에 별도 명시.

2.역할 정의

ROLE-001 · 기안자 (Drafter)
자신이 작성한 문서에 한해 기안·임시저장·회수 가능
ROLE-002 · 결재자 (Approver)
결재선상의 문서에 한해 승인/반려/보류
ROLE-003 · 대결자 (Delegate)
위임 기간 내 결재자 권한 대행
ROLE-004 · 시스템 관리자 (Admin)
조직·양식·결재선 마스터 관리. 데이터 수정 권한 없음
ROLE-005 · 감사자 (Auditor)
전 문서 읽기 + 감사 로그 조회. 수정 불가

3.권한 매트릭스

R=Read, W=Write, X=Execute, -=없음. 조건부는 (cond) 표기.
리소스 / 액션기안자결재자대결자Admin감사자
문서 작성W----
본인 임시저장 읽기R---R
결재선 지정W----
승인/반려-X (cond:in-line)X (cond:delegated)--
회수X (cond:own & not-approved)----
양식 마스터---WR
감사 로그 조회----R

4.위임 / 대결 규칙

Rule · 위임 기간
위임은 최대 30일. 종료일 도과 시 자동 해제.
Rule · 제외 항목
인사·예산·기밀 등급 문서는 위임 불가 (관리자 정책 키 delegation.excludeCategories).
Rule · 감사
대결 처리 시 원 결재자/대결자 모두 감사 로그에 기록.
