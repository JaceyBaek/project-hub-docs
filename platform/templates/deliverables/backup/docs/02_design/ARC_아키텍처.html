5.보안

  • 인증: SSO (OIDC, Azure AD)
  • 인가: ROLE 매트릭스 (ROLE-001..005)
  • 전송: TLS 1.2+, mTLS for internal
  • 저장: PostgreSQL TDE, S3 SSE-KMS
  • PII: 결재 의견의 사번/이름은 마스킹 후 로그

7.아키텍처 결정 기록 (ADR)

ADR-001 · 모놀리식 우선 (Modular Monolith)
결정초기 1년은 모듈형 모놀리식. 도메인 경계를 패키지로 분리해 후속 분할에 대비.
이유팀 규모 8명 / DDD 학습 곡선 / 운영 복잡도
결과배포 단위 1, DB 인스턴스 1, MQ는 audit-only
대안마이크로서비스 — 운영 인력 부족으로 기각
ADR-002 · 감사 로그를 별도 Kafka + S3
결정주 DB와 분리, Kafka → S3(append-only) 파이프라인
이유변조 방지 + 장기 보존 + 분석 워크로드 격리
결과최종 일관성 (≤5s), Athena로 ad-hoc 조회
