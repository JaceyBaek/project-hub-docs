3.기능 상세 — FUNC-001 기안문 저장

입력 (Request)
필드타입필수설명
formIdstringY양식 식별자
titlestring(80)Y제목
bodytextY본문 (HTML)
attachments[]fileN최대 5개 · 10MB
출력 (Response)
필드타입설명
idstring문서 UUID
statusenumDRAFT
createdAtdatetimeISO-8601
처리 로직 (Pseudocode)
1. 요청 검증 (title length, body 최소 10자, file mime/size)
2. 사용자 권한 확인 (ROLE-01 이상)
3. draft 엔티티 생성 → trx 시작
4. 파일 업로드 (S3) 후 메타데이터 저장
5. audit_log.append({action:"DRAFT_CREATED", ...})
6. trx 커밋 → 201 Created 반환

8.FAQ

Q. 임시저장과 상신의 차이는?
A. 임시저장은 DRAFT 상태로 본인만 열람, 상신은 PENDING으로 전환되며 결재자에게 알림이 전송됩니다.
