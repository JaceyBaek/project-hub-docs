1.사전 요구사항

  • ☐ Kubernetes 1.28+ · Helm 3.14+
  • ☐ PostgreSQL 15 · Redis 7 접근 가능
  • ☐ S3 버킷 및 IAM Role
  • ☐ Okta Application 등록 완료
  • ☐ HR API 액세스 키 발급 완료

2.설치 단계

1

네임스페이스와 Secret 준비

DB/Redis/SSO/HR 자격 증명을 Secret으로 등록합니다.
kubectl create namespace approval-prd kubectl -n approval-prd create secret generic db --from-literal=url=$DB_URL kubectl -n approval-prd create secret generic sso --from-literal=client_id=$OKTA_ID
2

values 파일 작성

환경에 맞는 values.prd.yaml 준비. (CFG v2 환경 대조표 참조)
image: tag: 2026.04.0 ingress: host: work.company.com env: MAX_UPLOAD_MB: 10 LOG_LEVEL: WARN
3

Helm 배포

helm upgrade --install approval ./charts/approval \ -f values.prd.yaml -n approval-prd --wait
4

DB 마이그레이션

kubectl -n approval-prd exec deploy/api -- ./app migrate
5

첫 HR 동기화

kubectl -n approval-prd create job --from=cronjob/sync-hr sync-hr-init

3.설치 후 검증 체크리스트

  • ☐ /healthz 200 OK (db · redis · sso · s3 모두 "ok")
  • ☐ SSO 로그인으로 관리자 계정 접속 확인
  • ☐ 기안문 1건 작성 → 상신 → 결재 시나리오 E2E
  • ☐ 첨부 10MB 업로드 성공
  • ☐ Grafana Alert 테스트 → Slack 수신
  • ☐ 백업 작업 수동 1회 실행 → 복구 검증
