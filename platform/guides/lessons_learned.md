> 새 항목은 해당 카테고리 섹션 **최상단**에 추가 — 최신 항목이 항상 위에 오도록 유지.

---

## 에스컬레이션 흐름

```
[프로젝트 발생]
프로젝트 _manage/lessons.md
  → [공통] 태그 부착
    → 세션 마무리 또는 명시 요청 시
      → platform/guides/lessons_learned.md 승격

[플랫폼 레이어 발생]
platform/guides/lessons_learned.md 직접 기록
(플랫폼 레이어 이슈는 출처가 공통이므로 에스컬레이션 불필요)
```

## 협업/프로세스

### [협업/프로세스] 플랫폼 정책은 메모리가 아닌 hub 문서에 기록해야 한다
- **상황**: AI 비서가 플랫폼 운영 규칙(테스트 코드 프로젝트 분리 원칙, 승격 심사 프로세스 필요성)을 개인 메모리(`~/.claude/.../memory/`)에 저장함. CLAUDE.md 14번 규칙에 명시되어 있었음에도 실행 시 적용 누락.
- **원인**: 작업 흐름(메모리 저장 패턴)이 먼저 실행되고 규칙 확인이 뒤처짐. 규칙이 존재해도 실행 단계에서 누락될 수 있음.
- **재발방지**: 저장 전 "이 내용이 다른 사용자·세션·머신에서도 같은 효력을 가져야 하나?" 판단 먼저. YES면 hub 문서, NO면 메모리. / 규칙을 추가로 늘리는 것은 준수율을 높이지 않음 — 위반 시 즉시 지적·수정이 실질적으로 효과적.
- **출처**: 플랫폼 레이어 / 2026-05
