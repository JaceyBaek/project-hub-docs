1.환경 변수

키기본값허용값설명 / 변경 영향
APP_ENVproddev / qa / prod로깅 레벨·기본 정책 분기. 재시작 필요.
DB_URL—JDBC URLRDS 접속 정보. 재시작 필요. 비밀로 분리(SSM).

LOG_LEVELINFODEBUG / INFO / WARN / ERROR핫리로드 가능 (SIGHUP).

키기본값설명

3.비밀 키 회전

대상주기절차
DB 비밀번호90일SSM Parameter Store rotation → 앱 롤링 재시작
KMS 키 (S3)1년새 키 생성 → 이중 인증 후 환경변수 교체
OIDC client_secret180일Azure AD에서 신규 secret 발급 후 SSM 갱신
⚠ 주의
비밀 값은 Confluence / Git에 직접 기록하지 않는다. 본 문서에는 키 경로만 표기.

4.적용 절차

  1. 1) Stage 환경에서 변경 적용 (SSM/Admin Console)
  2. 2) 회귀 테스트 (UTC/ITS 핵심 시나리오)
  3. 3) Production 적용 — 핫리로드 가능 키는 SIGHUP, 그 외 롤링 재시작
  4. 4) 변경 사항을 본 문서에 반영 후 PR
