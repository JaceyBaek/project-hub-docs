1.개요

대상 시스템 흐름의 범위와 가독 규칙을 1~2문단으로.

본 문서는 전자결재의 핵심 비즈니스 프로세스를 서술한다. 각 흐름은 ID(EM2026-FLW-###)로 식별되며, 상위 요구사항(REQ)과 하향 화면(SCR)·기능(FUNC)에 양방향 추적된다.

2.액터 정의

시스템 외부에서 흐름을 트리거하거나 의사결정하는 주체. 최소 2명.
기안자 (Drafter)
문서 작성·상신·회수. 자신이 작성한 문서만.
결재자 (Approver)
승인·반려·보류. 결재선상의 문서만.
대결자 (Delegate)
결재자 부재 시 위임 권한으로 결재.

3.흐름 목록

전체 흐름 카탈로그. 본 문서가 다루는 흐름은 모두 여기에.

4.표준 흐름 상세

각 흐름은 트리거 / 입력 / 표준 경로 / 분기 / 출력 5요소.
FLW-001 · 기안→결재 표준 흐름
트리거기안자가 결재 양식 선택 후 "상신" 클릭
입력제목·본문·첨부·결재선·합의자·참조자
출력완결된 결재 문서 + 감사 로그 1건
SLA상신 → 1차 결재 알림 ≤ 30초

표준 경로

  1. S01 기안문 작성 (양식·본문) — SCR-001
  2. S02 결재선 지정 — SCR-002 / FUNC-002
  3. S03 상신 (POST /approvals) — FUNC-001
  4. S04 결재자 알림 발송 (Push/메일)
  5. S05 결재자 검토 후 승인/반려 — SCR-003 / FUNC-003
  6. S06 다음 결재자로 이동 (반복)
  7. S07 최종 승인 → 완결 + 감사 로그

분기

  • S05에서 반려 → 기안자에게 회신, 수정 후 재상신 가능
  • S05에서 합의자 단계인 경우 결재선 영향 없이 의견만 회신
FLW-002 · 모바일 결재

FLW-001과 동일하되, 결재자 단계만 모바일 앱에서 수행. 첨부 파일은 미리보기로 제한.

  1. S01 모바일 푸시 알림 수신
  2. S02 앱 내 결재 화면 — SCR-010
  3. S03 지문/PIN 인증 후 처리 — FUNC-020

5.예외 / 보상 흐름

표준 경로에서 벗어난 케이스. 발생 조건과 복구 절차 명시.
Exception · E01 — 결재자 부재
발생. S05 단계에서 결재자가 휴직/퇴사 상태 → 처리. 시스템이 대결 규칙(ROLE-003) 자동 적용 → 대결자에게 라우팅. 알림. 기안자에게 라우팅 사실 통지.
Exception · E02 — 회수
발생. S04~S06 사이 기안자가 "회수" 클릭 → 처리. 진행 중인 단계 취소, 임시저장 상태로 복귀. 제약. 1단계라도 승인 완료 시 회수 불가.
