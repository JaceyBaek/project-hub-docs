1.개요

본 문서는 백엔드 기능을 API 단위로 정의한다. 각 기능은 상위 SCR/REQ에서 호출되며, 하향 UTC에 매핑된다.

3.기능 상세

FUNC-001 · 기안문 임시저장
시그니처PUT /drafts/{id}
권한ROLE-001 (본인 문서만)
입력{title, formId, bodyHtml, attachments[], approverLine?}
출력{id, version, updatedAt}
트랜잭션단일 트랜잭션. 첨부 메타만 갱신, 파일은 별도 FUNC-004.

처리 규칙

  • 제목 공백 시 400
  • 본문 50KB 초과 시 413
  • 다른 사용자의 draft 갱신 시 403

예외

  • DRAFT_NOT_FOUND · 404
  • BODY_TOO_LARGE · 413
FUNC-003 · 결재 처리
시그니처POST /approvals/{id}/decisions
권한ROLE-002 (결재선상) · ROLE-003 (위임)
입력{decision: 'APPROVE'|'REJECT'|'HOLD', comment?}
출력{nextApproverId?, finalState?}
트랜잭션결재 상태 갱신 + 다음 결재자 큐 + 감사 로그 ─ 단일 TX

처리 규칙

  • 현재 결재 단계 사용자가 아니면 403
  • REJECT 시 comment 필수
  • 최종 결재자 승인 시 finalState=COMPLETED + 알림 발송
FUNC-020 · 위임 적용

결재 라우팅 시 위임 규칙(ROLE-003)을 평가해 대결자로 전환한다. 카테고리 제외 정책 적용.

시그니처POST /delegations/apply
입력{approvalId, currentApproverId}
출력{effectiveApproverId, viaDelegation: boolean}
