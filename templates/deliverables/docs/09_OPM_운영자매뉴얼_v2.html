3.Playbook 카드

PB-001P1 · 5분 SLA

API 전체 5xx 급증

증상 5xx rate > 5% / 1min
1차 최근 배포 확인 → Rollback
2차 DB / Redis / SSO 순서로 점검
Escalation 10분 내 미해결 → SRE On-call
PB-002P1 · 5분 SLA

SSO 인증 전면 불가

증상 로그인 성공률 < 50%
1차 Okta 상태 페이지 확인
2차 비상용 로컬 인증 플래그 ON (FEATURE_LOCAL_AUTH=true)
PB-010P2 · 30분 SLA

첨부 업로드 실패

증상 S3 4xx/5xx 증가
1차 IAM 자격 증명 만료 여부 확인
PB-011P2 · 30분 SLA

배치 sync-hr 실패

증상 01:00 배치 FAILED
1차 HR API 응답 확인 → 수동 재실행
수동 재실행 kubectl create job --from=cronjob/sync-hr …
PB-012P2 · 30분 SLA

결재 라우팅 지연

증상 큐 depth > 1000
대응 Consumer Pod 2배 증설 → 해소 후 원복
PB-013P2 · 30분 SLA

모바일 Push 미수신

1차 FCM/APNs 키 만료 확인 (→ CFG)
